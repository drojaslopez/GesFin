# Diseño Técnico: Metas y Prorrateo

## Capa de Dominio
- **Entidades:** `Goal`, `Contribution`, `MemberQuota`.
- **Lógica de Negocio:** Cálculo de cuotas equitativas y porcentaje de cumplimiento acumulado.

## Capa de Aplicación
- **Caso de Uso:** `GoalService` (creación de metas, prorrateo y registro de aportes).

## Adaptadores y Persistencia
- **Repositorios JPA:** `GoalRepositoryAdapter` mapeado a tablas de PostgreSQL.
- **Base de Datos Pruebas:** H2 en memoria / Testcontainers.
