# Propuesta: Gestión de Metas y Prorrateo de Cuotas

## Problema
Los grupos familiares necesitan definir metas de ahorro conjuntas con una distribución transparente y equitativa entre sus integrantes.

## Solución
Implementar el caso de uso `GoalService` para gestionar la creación de metas y la asignación inicial de cuotas en partes iguales entre los miembros activos.

## Criterios de Aceptación
- Creación exitosa de una meta asignando cuotas equitativas.
- Registro de aportes individuales con actualización automática del porcentaje de progreso.
